# 记忆管理台

管理台采用 Vue 3、TypeScript 和 Vite，普通 CSS 提供浅色／深色外观。构建产物由现有 Express 的根路径 `/` 提供，沿用当前应用容器、端口和域名，无需增加常驻容器或数据库迁移。

## Docker 配置

在部署目录的私密 `.env` 中设置 `ADMIN_PASSWORD`，长度为 16–1024 字符。也可在 Docker 的环境变量配置中提供同名变量。真实值不要写入聊天、Git、报告或共享记忆；使用 Compose `.env` 时，如密码包含 `$`，用单引号包住整个值以避免变量插值。

本仓库两个 Compose 模板已经传入此变量。构建并更新应用：

```sh
docker compose up -d --build --no-deps app
```

通过 `PUBLIC_URL` 对应的根路径访问管理台。配置 HTTPS 时，会话 Cookie 带 Secure 属性。

`ADMIN_PASSWORD` 未设置或为空时，登录关闭，页面显示配置说明；原有 MCP 和 Bearer Token REST 继续可用。密码不符合长度要求时启动失败。修改变量后必须重新创建 app 容器（仅 restart 不会加载 Compose 新环境变量），所有旧会话随进程退出而失效。

## 登录与权限

- 密码仅在服务端用于 scrypt 校验，不下发给前端、不写入业务数据库。
- 登录建立随机会话，服务端仅保存其摘要，HttpOnly / SameSite=Strict Cookie 有效期固定为 12 小时；退出立即删除服务端会话。
- 单应用进程内保存最多 1000 个未过期会话；容器重启后重新登录。适用于当前单容器部署。
- 管理台是单用户管理入口，拥有全部记忆与状态的管理权限，写入来源客户端为 `web-admin`。
- 登录每个来源 IP 每分钟限 5 次，沿用全局限流；经 NPM 等代理时需正确设置 `TRUST_PROXY`，否则多个用户共享代理 IP 配额。
- 登录要求自定义请求头，所有请求沿用 Origin 白名单。Cookie 认证的 REST POST 和退出要求会话 CSRF Token。Cookie 不用于 `/mcp`；显式 Authorization 请求仍按原 Bearer 权限验证。
- 页面启用 CSP 和禁止嵌入，正文、来源和历史按纯文本展示；不执行其中 HTML、脚本或指令。外观偏好可存入 localStorage，密码、会话与记忆正文不存入浏览器持久存储。

## 功能与规则

分区导航、游标分页、混合检索和降级提示；按标签、类型过滤，支持显式包含子分区。搜索按相关性最多返回 50 条，完整浏览使用分页。全部分区浏览最多同时覆盖 20 个分区，更多时需选定分区，界面会明确提示。

详情展示正文、属性、来源与历史版本。新建或编辑提交完整属性，编辑固定 namespace/key，携带读取时的 `expected_version`。网络失败后未改变的同一操作复用幂等键；版本冲突展示服务端内容，不自动覆盖，加载最新版本需明确放弃草稿。删除二次确认并按版本执行，清除正文、来源、历史，旧备份到期前可能仍保留。

分区总览作为 `key=overview` 的普通记忆维护；界面提示长期有效与自动置顶。管理台不会自动生成或重建总览，新增重要事实或删除条目后，用户应核对相关总览摘要。

服务状态页展示当前有效、置顶及过期数量，以及 PostgreSQL、Qdrant、Embedding、索引覆盖、积压与失败任务；不调用外部整理 API，不触发模型推理。
