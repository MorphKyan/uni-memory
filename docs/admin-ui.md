# 记忆管理台

管理台采用 Vue 3、TypeScript 和 Vite，提供浅色与深色外观。现有应用容器在根路径 `/` 提供页面，启动时自动运行 PostgreSQL 迁移。

## Docker 配置

在部署目录的私密 `.env` 中设置 `ADMIN_PASSWORD`，长度为 16–1024 字符。也可在 Docker 的环境变量配置中提供同名变量。真实值不要写入聊天、Git、报告或共享记忆；使用 Compose `.env` 时，如密码包含 `$`，用单引号包住整个值以避免变量插值。

本仓库两个 Compose 模板已经传入此变量。构建并更新应用：

```sh
docker compose up -d --build --no-deps app
```

通过 `PUBLIC_URL` 对应的根路径访问管理台。配置 HTTPS 时，会话 Cookie 带 Secure 属性。

`ADMIN_PASSWORD` 启用管理台并提供初始密码，留空可关闭网页登录。首次从管理台改密后，数据库内的密码摘要优先于环境变量。环境变量的修改须重新创建 app 容器才能加载。

## 登录与权限

- 在「访问管理 → 管理员密码」输入当前密码并确认新密码。服务端只保存带盐的 scrypt 摘要，更新成功后立即注销所有管理台会话，新密码在重启后继续有效。忘记密码时，具备数据库管理权限的运维人员可删除 `admin_password` 的单例记录，并重新创建应用容器，以私密环境变量中的密码重新启用登录。
- 登录建立随机会话，服务端仅保存其摘要，HttpOnly / SameSite=Strict Cookie 有效期固定为 12 小时；退出立即删除服务端会话。
- 单应用进程内保存最多 1000 个未过期会话；容器重启后重新登录。适用于当前单容器部署。
- 管理台是单用户管理入口，拥有全部记忆与状态的管理权限，写入来源客户端为 `web-admin`。
- 登录和改密共享每来源每分钟 5 次的限额，同时受全局限流约束。经 NPM 等代理时，`TRUST_PROXY` 影响服务如何识别来源以实施限流。
- 登录要求自定义请求头，所有请求沿用 Origin 白名单。Cookie 认证的 REST POST 和退出要求会话 CSRF Token。Cookie 不用于 `/mcp`；显式 Authorization 请求仍按原 Bearer 权限验证。
- 页面启用 CSP 和禁止嵌入，正文、来源和历史按纯文本展示；不执行其中 HTML、脚本或指令。外观偏好可存入 localStorage，密码、会话与记忆正文不存入浏览器持久存储。

## 记忆库

分区导航、游标分页、混合检索和降级提示。按普通标签、设备标签和类型过滤，支持显式包含子分区。设备筛选可用逗号输入多个计算机名，条目须包含全部指定的设备。编辑记忆时可维护设备列表。搜索按相关性最多返回 50 条，完整浏览使用分页。全部分区浏览最多同时覆盖 20 个分区，更多时需选定分区，界面会明确提示。

详情展示正文、属性、来源与历史版本。新建或编辑提交完整属性，编辑固定 namespace/key，携带读取时的 `expected_version`。网络失败后未改变的同一操作复用幂等键；版本冲突展示服务端内容，不自动覆盖，加载最新版本需明确放弃草稿。删除二次确认并按版本执行，清除正文、来源、历史，旧备份到期前可能仍保留。

分区总览作为 `key=overview` 的普通记忆维护；界面提示长期有效与自动置顶。管理台不会自动生成或重建总览，新增重要事实或删除条目后，用户应核对相关总览摘要。

## Bearer 凭据

「访问管理 → Bearer 凭据」列出与 CLI 共用的静态 Bearer，包括客户端标识、权限、有效期和撤销状态。可以签发新令牌、修改客户端标识及权限和到期时间、轮换令牌、撤销访问。改名会改变后续记忆写入的客户端标识及幂等范围。轮换保留凭据 ID 并立即使旧令牌失效。已撤销记录保留供审计。令牌明文只在签发或轮换成功时显示一次。OAuth 授权仍通过原 OAuth 流程管理。

## 运行与审计

服务状态页展示当前有效、置顶及过期数量，以及 PostgreSQL、Qdrant、Embedding、索引覆盖、积压与失败任务。请求审计按时间、入口、结果及客户端筛选，可查看请求量趋势、结果分布和分页明细。点击每行的「查看详情」打开弹窗。

审计记录到达应用的 REST、MCP、OAuth、管理操作及其他动态请求，含查询、拒绝、失败和中途断开。明细显示请求 ID（响应头 `X-Request-ID`）、客户端和凭据 ID、来源 IP、开始时间、应用内请求耗时、HTTP 方法、归一化路由、状态、MCP 方法与工具名、已知错误码、声明字节数和筛选参数概况。来源 IP 取应用根据 `TRUST_PROXY` 解析出的单个地址。请求在上游被拦截时，应查询相应代理的日志。

记忆写入和删除记录服务解析出的目标记忆 ID、变更结果、可用的记忆版本及幂等重试标记。记忆读取记录返回条数，单条获取另记来源条数，列表另记是否有下一页。搜索记录是否降级，以及实际执行的 PostgreSQL、Embedding 和 Qdrant 阶段耗时。MCP 批量请求在同一条 HTTP 记录中展示各工具的结果和耗时。新增字段仅适用于升级后的请求。审计避开原始代理头、记忆正文和来源、查询原文、原始 URL 参数、凭据值和 Cookie。

审计在响应结束后异步写入 PostgreSQL。数据库故障或写入积压时，应用记录 `request_audit_unavailable`，该时段可能缺少部分审计记录。静态资源、会话状态检查和审计读取本身从审计中排除。数据从本次升级后开始积累，保留在 PostgreSQL，界面支持查询最近 365 天。
